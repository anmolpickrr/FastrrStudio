# Reel and spin videos

The Work section and the lightbox play MP4s from this folder. The files are not committed yet,
so the cards currently show their still frames.

To turn video on:

1. Add the MP4s below (H.264, 9:16, ideally 720×1280 and under ~5 MB each for the web).
2. In `assets/js/data.js`, set `var VIDEOS_READY = true;`.
